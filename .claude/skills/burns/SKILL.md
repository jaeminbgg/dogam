# 번스 글쓰기

사용자가 "번스"라고 하면 아래 양식으로 글을 써 준다.

## 양식

```
번스 제○일차 글주제: ○○○

(본문)
```

- 첫 줄: `번스 제○일차 글주제: ○○○` 형식의 제목
  - `○일차`: 사용자가 말한 숫자 (예: "번스 15일차", "번스 15")
  - `○○○`: 사용자가 말한 글 주제
- 둘째 줄: 빈 줄 하나
- 셋째 줄부터: 주제에 대한 본문을 바로 시작한다. 인사말, 머리말, "다음은 ~입니다" 같은 설명 없이 본문만 쓴다.

## 진행 방법

1. 사용자 말에서 일차 숫자와 주제를 찾는다.
2. 주제가 없으면 "오늘 번스 글 주제가 무엇인가요?" 한 줄만 묻는다.
3. 일차 숫자가 없으면 이 대화에서 앞서 쓴 번스 글의 일차에 1을 더한다. 그것도 모르면 `제○일차`를 비워 두지 말고 "몇 일차인가요?"를 주제 질문과 함께 한 번에 묻는다.
4. 사용자가 본문 내용(메모, 생각, 경험)을 함께 주면 그 내용을 살려 다듬는다. 주제만 주면 그 주제로 직접 쓴다.
5. 결과는 양식 그대로만 출력한다. 글 앞뒤에 덧붙이는 설명은 하지 않는다.

## 본문 쓰기 기준

- 매일 올리는 짧은 글이므로 분량은 기본 3~6문단 정도로 한다. 사용자가 길이를 정하면 그대로 따른다.
- 사용자 본인이 쓰는 1인칭 글처럼 자연스러운 한국어로 쓴다.
- 마크다운 제목(#)·굵은 글씨·글머리표는 쓰지 않는다. 그대로 복사해 붙여 넣을 수 있는 평문으로 쓴다.

## 예시

사용자: 번스 12일차, 주제는 아침 산책

출력:

```
번스 제12일차 글주제: 아침 산책

오늘도 해가 뜨기 전에 집을 나섰다. ...
```
